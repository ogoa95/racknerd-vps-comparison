## 常见问题

**特价套餐能退款吗？**

默认不能。退款按个案酌情处理，只有明显服务端故障（如刚开通 VPS 就无法启动）才有可能争取。介意的话，先用常规 KVM 套餐按月付试水，满意再转年付特价。

**续费时真的和首年一个价吗？**

是。官方 FAQ 明确特价套餐 "lifetime recurring"，续费按购买时的价格计算。到期前 14 天系统自动出账单，也可以提前在后台手动生成续费账单锁价。

**能装 Windows 吗？**

官方系统列表里没有 Windows，但支持通过工单申请自定义 ISO 安装，部署后也可用 HTML5 VNC 控制台自行安装。1 GB 内存的套餐跑 Windows 会很勉强，这类需求建议直接看 4 GB 以上。

**取消服务后数据还在吗？**

不在。发起立即取消后 24 小时内服务终止、数据全部删除且不可恢复。确定要取消前，先备份数据。
